#+TITLE: Lisp-RPC Rust Generator

[[https://crates.io/crates/lisp-rpc-rust-generator][https://img.shields.io/crates/v/lisp-rpc-rust-generator.svg]]
[[https://docs.rs/lisp-rpc-rust-generator][https://docs.rs/lisp-rpc-rust-generator/badge.svg]]

Command-line application for generating Rust code from Lisp-RPC protocol files.

** Project Structure

*** templates

Templates used for code generation.

*** src

Core logic that reads templates and specifications to generate code.

** Usage

After building:

#+begin_src shell
  lisp-rpc-rust-generator \
          --input-file spec.lisprpc \
          --templates-path ./templates/ \
          --output-path .
#+end_src

In most cases, you don't need to provide the templates folder, as the generator can use its embedded templates:

#+begin_src shell
  lisp-rpc-rust-generator \
          --input-file spec.lisprpc \
          --output-path .
#+end_src

To also generate RPC trait implementations for the RPC server, pass =--with-server= (or =-w=):

#+begin_src shell
  lisp-rpc-rust-generator \
          --input-file spec.lisprpc \
          --output-path . \
          --with-server
#+end_src

Check the [[file:../../examples/rust/spec-mode-generate-lib/][example]] for more details.
