#+TITLE: Serialize Struct to Lisp-RPC Demo

This is a demo Actix server that demonstrates how to use the =lisp-rpc-rust-serializer= to handle serialized data in Lisp-RPC format.

** Run the server

#+begin_src shell
cargo run
#+end_src

** Test Endpoints

*** JSON Endpoint

The server listens on =http://127.0.0.1:8080/req-json= and expects a JSON payload.

#+begin_src shell
curl -X POST http://127.0.0.1:8080/req-json \
     -H "Content-Type: application/json" \
     -d '{
           "time": 8736,
           "body": { "raw": "hello lisp-rpc" }
         }'
#+end_src

*** Lisp-RPC Endpoint

The server listens on =http://127.0.0.1:8080/req-lisp= and expects a raw Lisp-RPC string.

#+begin_src shell
curl -X POST http://127.0.0.1:8080/req-lisp \
     -H "Content-Type: text/plain" \
     -d "(req :time 9527 :body (body :raw \"hello lisp-rpc\"))"
#+end_src
