* README

~utils~ contains various tools for Lisp-RPC development and validation.

** Spec Validation

To validate a spec file:

#+begin_src lisp
  (lisp-rpc-checker:spec-check-file "spec-file")
#+end_src

** Running Tests

To run the utility tests:

#+begin_src lisp
  (load "./utils.asd")
  (ql:quickload "utils")
  (asdf:test-system :utils)
#+end_src
