#+TITLE: Lisp-RPC (Common Lisp Implementation)

The Common Lisp implementation of ~lisp-rpc~.

* Install

If you use ~quicklisp~, you can clone this repository into ~~/quicklisp/local-projects~ and load the system in your Lisp environment.

Then run ~./make.sh~ (requires ~sbcl~) to build the executable binary ~lisp-rpc-gen~ for spec generation mode.

* Usage

** Homoiconic Usage

Thanks to Lisp's homoiconicity, Lisp-RPC data expressions can be invoked directly as standard function calls.

Check this [[file:examples/homoiconic.lisp][example]] for more details.

** Plain Mode

Parse raw Lisp-RPC S-expression strings into raw data objects.

Check this [[file:examples/raw-data.lisp][example]] for more details.

** Spec Mode & Code Generation

Just like the Rust version, Lisp code can be generated directly from a spec file. Given a spec like [[file:examples/spec-demo.lisp][spec-demo.lisp]], run:

#+begin_src shell
  lisp-rpc-gen gen spec-demo.lisp
#+end_src

This generates the ~demo~ package code.

** RPC Server

The Common Lisp RPC server runs on *Woo* (an asynchronous, high-performance HTTP server built on libev).

*** Server Example:

#+begin_src lisp
  (use-package :lisp-rpc-server)

  ;; 1. Initialize server
  (defparameter *server* (make-rpc-server :port 5000))

  ;; 2. Register handler (validated against rpc-endpoint-p)
  (register-rpc-handler *server* 'demo:get-book
    (lambda (req)
      ;; req is automatically deserialized into a #S(DEMO:GET-BOOK ...) struct
      (demo:make-book-info
       :title (demo:get-book-title req)
       :id "12345")))

  ;; 3. Start server
  (start-server *server*)
#+end_src
