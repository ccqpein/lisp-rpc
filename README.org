#+TITLE: Lisp-RPC

Lisp-RPC is a lightweight, S-expression based Remote Procedure Call protocol designed for simplicity and flexibility. It supports two primary modes of operation to balance dynamic communication with type safety and performance.

* Overview

- *Plain Mode*: For direct, dynamic communication using raw S-expressions.
- *Spec Mode*: For schema-defined, type-checked communication with automatic code generation.

* Data Types

Lisp-RPC supports standard Lisp-like data structures:
- *Primary Types*: =string=, =number=, =boolean= (represented by =T= and =NIL=).
- *Complex Types*:
  - *Data*: Named structures with keyword-value pairs: =(name :key value)=.
  - *List*: Quoted sequences: ='(1 2 3)=.
  - *Map*: Anonymous keyword-value pairs: ='(:key value)=.

* Usage Modes

** Plain Mode
In Plain Mode, clients send raw S-expressions as strings. The server parses these expressions dynamically.
#+begin_src lisp
  (get-book :title "The Hobbit" :year 1937)
#+end_src

** Spec Mode
Spec Mode uses a formal schema defined with =def-msg= and =def-rpc=. This enables generating typed libraries for various languages.

#+begin_src lisp
  (def-msg book-info :title 'string :id 'number)
  (def-rpc get-book '(:title 'string) 'book-info)
#+end_src

* Examples

** Serialize Structure

Structures that derive ~Serialize~ and ~Deserialize~ can use ~lisp_rpc_from_str~ and ~lisp_rpc_to_str~ from ~lisp_rpc_rust_serializer~ to serialize and deserialize between the structure and the Lisp-RPC format string.

Check this [[file:examples/rust/serialize-struct-to-lisprpc/][example]] for more details.

** Handle the plain mode

~lisp_rpc_rust_parser::data::Data~ can parse a string directly into a ~Data~ object, which can then be accessed using ~.get(keyname)~.

Check this [[file:examples/rust/plain-mode-read-and-write-data/][example]] for more details.

** Spec & generate mode

[[file:examples/rust/spec-mode-generate-lib/][spec-mode-generate-lib]] shows how to generate the Lisp-RPC library code with the generator.
