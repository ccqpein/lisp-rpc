* README

The generator for generating Rust code from Lisp-RPC protocol files.

** Project Structure

*** templates

Templates used for code generation.

*** src

Core logic that reads templates and specifications to generate code.

** Usage

After building:

#+begin_src shell
lisp-rpc-rust-generator \
      --input-file spec.lisprpc\
          --templates-path ./templates/ \
          --output-path .
#+end_src

I believe in most cases, we don't need give the templates folder.

#+begin_src shell
  lisp-rpc-rust-generator \
      --input-file spec.lisprpc\
      --output-path .
#+end_src

check the [[file:~/Code/lisp-rpc/examples/rust/spec-mode-generate-lib/][example]]
